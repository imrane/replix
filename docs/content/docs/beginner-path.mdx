---
title: Beginner Path
description: The simple habit for day one users.
---

## 1) Install in your repo

Use your normal toolchain (`npm`, `pnpm`, or `bun`).

## 2) Add one pack by name

```bash
npx replix add github:owner/rpacks starter
```

## 3) Apply and verify

```bash
npx replix
npx replix check
```

If check is in sync, you are good.
