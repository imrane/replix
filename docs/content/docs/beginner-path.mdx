## The habit (2 commands, 30 seconds)

Run these after adding a new pack or pulling from a teammate:

```bash
npx replix          # apply (generate/update files)
npx replix check    # verify (nothing drifted)
```

If `check` is clean, you're done.

---

## Day 1: get your first pack

The `starter` pack is the best place to begin — it ships a skill, a command, and an agent with no required vars.

```bash
# Install once per repo
npm install -D replix

# Add the starter pack
npx replix add github:myorg/ai-packs starter

# Apply it
npx replix

# Confirm
npx replix check
```

You should see:

```
✅ outputs in sync
```

Your `.claude/skills/repo-status/`, `.claude/commands/review.md`, and `.claude/agents/security.md` now exist. Open your AI agent and type `/review` to use the command.

---

## Add a second pack

Want writing tools? Add `content-pack` which includes the `humanizer` skill:

```bash
npx replix add github:myorg/ai-packs content
npx replix
npx replix check
```

Now `.claude/skills/humanizer/` is also available. Your agent uses it automatically.

---

## Day 2+: keeping things fresh

When a teammate adds a new pack or you pull new commits:

```bash
npx replix          # re-apply (idempotent — safe to run any time)
npx replix check    # confirm
```

`replix` is idempotent. If nothing changed, it skips emit entirely:

```
✅ Replix: no changes (state hash matches), skipping emit
```

---

## When things go wrong

Run doctor first:

```bash
npx replix doctor
```

It tells you exactly what's missing and how to fix it. See [Troubleshooting →](./troubleshooting).
