## replix (apply)

Generate or update client-native files from your enabled packs.

```bash
npx replix [--config <path>]
```

| Flag | Default | Description |
|---|---|---|
| `--config` | auto-discover | Path to `.replix/repo.json` |

**Output (changes emitted):**
```
🔧 Replix: loading config...
📦 Replix: emitting outputs...
✅ Replix: done
```

**Output (no changes):**
```
✅ Replix: no changes (state hash matches), skipping emit
```

## replix check

Detect drift between config and generated files. Non-mutating, CI-safe.

```bash
npx replix check --config <path>
```

**Output (in sync):**
```
✅ outputs in sync
```

**Output (drift):**
```
❌ outputs drifted from config
  ADD    .claude/skills/humanizer/SKILL.md
  MODIFY .mcp.json
  REMOVE .claude/skills/old-skill/SKILL.md
Run `replix` to regenerate.
```

Exit code: `0` (in sync), non-zero (drift).

## replix doctor

Diagnose config health: missing vars, lock drift, pack readiness.

```bash
npx replix doctor [--config <path>]
```

**Output:**
```
✅ config: ok
✅ lock: in sync (rev=abc1234)
variable matrix:
  [ok] pack=config var=PROJECT_ROOT source=builtin usedBy=filesystem
  [ok][secret] pack=content-pack var=API_TOKEN source=file usedBy=pack.vars.required
  [missing] pack=content-pack var=WEBHOOK_SECRET source=missing usedBy=pack.vars.optional
    fix: write secret to .replix/vars/WEBHOOK_SECRET (recommended), or set WEBHOOK_SECRET_FILE, or export WEBHOOK_SECRET
✅ pack content-pack: ready
```

Exit code: `0` (ok), `2` (blocking issues).

## replix init

Scaffold `.replix/repo.json` and a vars example file.

```bash
npx replix init [--client claude] [--with-lock] [--force]
```

| Flag | Description |
|---|---|
| `--client` | Target client (claude, opencode, codex) |
| `--with-lock` | Also write an empty `replix.lock.json` |
| `--force` | Overwrite existing files |

**Output:**
```
✅ Wrote .replix/repo.json
✅ Wrote .replix/vars/.example
```

## replix add

Add a pack by source, name, URL, or search term.

```bash
npx replix add <source> [pack-name] [--dry-run] [--allow-risky]
```

**Examples:**

```bash
# By shorthand name
npx replix add github:myorg/ai-packs content

# By direct source
npx replix add "github:myorg/ai-packs?rev=abc1234&pack=content"

# From ClawHub (individual skills — ClawHub is a skills marketplace)
npx replix add clawhub:humanizer

# Plain search term
npx replix add "plain language writer"

# Preview without writing
npx replix add github:myorg/ai-packs content --dry-run
```

**Output:**
```
✅ replix add: added
   source: github:myorg/ai-packs?pack=content@abc1234
```

## replix search

Search across all registered providers.

```bash
npx replix search "writing assistant" [--provider clawhub]
```

```
provider: clawhub
- humanizer   Humanize AI output for real humans   https://...   sec:verified   trust:trusted/low
- tone-fix    Fix tone in generated docs            https://...   sec:unknown    trust:review/medium
```

> ClawHub publishes individual **skills**. Replix packs (bundles of skills + commands + agents + hooks + MCP) are a Replix spec — no external publishers yet.

## replix spec validate-client-shapes

Check client-shape snapshots for freshness and emit refresh checklists.

```bash
npx replix spec validate-client-shapes [--max-age-days N]
```

```
✅ src/clientPlugins/claude/client-shape.snapshot.json
⚠️  src/clientPlugins/opencode/client-shape.snapshot.json
    warn: snapshot approaching expiry (22d old, expires at 30d)

📋 Refresh checklist for opencode (22d old):
  1. Review current opencode docs at the source URLs below
     - https://opencode.ai/docs/config
  ...
```

Exit code: `0` (all ok), `1` (warnings only), `2` (errors).
