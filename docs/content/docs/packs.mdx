## What's in a pack?

A pack is a versioned bundle you add to your repo. Each pack can contain any mix of:

| Thing | What it does |
|---|---|
| **Skills** | Markdown context injected into your AI agent |
| **Commands** | Slash commands (`/review`, `/audit`, `/outline`) |
| **Agents** | Specialized AI modes (security reviewer, editor, analyst) |
| **Hooks** | Lifecycle triggers (pre-commit, post-tool-call) |
| **MCP** | Model Context Protocol server configs |

Example packs (all real, in our fixtures):

| Pack | Skills | Commands | Agents |
|---|---|---|---|
| `starter` | `repo-status` | `/review` | `security` |
| `security` | `threat-model` | `/audit` | `red-team` |
| `content` | `humanizer` | `/outline` | `editor` |
| `dataops` | `sql-analyst` | `/report` | `analyst` |

## Add a pack

**By name** (when the pack repo uses a name index):

```bash
npx replix add github:myorg/ai-packs starter
```

```
🔍 Resolving github:myorg/ai-packs starter...
✅ replix add: added
   source: github:myorg/ai-packs?pack=starter@abc1234
```

**By direct source** (pinned):

```bash
npx replix add "github:myorg/ai-packs?rev=abc1234&pack=starter"
```

**From ClawHub** (individual skills — ClawHub is a skills marketplace, not a pack registry):

```bash
npx replix add clawhub:humanizer
# or paste the skill URL
npx replix add https://clawhub.ai/items/humanizer
```

## What a pack gives your repo

After `replix add github:myorg/ai-packs content` + `replix`:

```
.claude/skills/humanizer/SKILL.md     ← Claude reads the humanizer skill
.claude/commands/outline.md           ← /outline command available
.claude/agents/editor.md              ← editor agent available
.opencode/skills/humanizer/SKILL.md
.opencode/command/outline.md
.opencode/agent/editor.md
.mcp.json
opencode.json
```

## Search and browse

```bash
npx replix search "code review"
```

```
provider: clawhub
- humanizer    Plain-language writing skill for AI agents   trust:trusted/low
- sql-analyst  SQL query and analysis skill                 trust:trusted/low
- repo-status  Repo context skill for coding agents         trust:trusted/low
```

> **Note:** ClawHub publishes individual skills. Replix packs (which bundle skills + commands + agents + hooks + MCP) are a Replix concept — no external pack registry exists yet. Our own fixture packs (`starter`, `security`, `content`, `dataops`) are the reference implementations.

**Interactive browser:**

```bash
npx replix browse "writing"
```

Use `j`/`k` to navigate, `Space` to select, `Enter` to install, `/` to filter.

## Upgrade packs

```bash
npx replix pack upgrade
```

```
🔄 Checking for updates...
  starter: abc1234 → def5678 (new version available)
✅ pack upgrade: done. Run `replix` to apply.
```

---

## Remove a pack

```bash
npx replix pack uninstall "github:myorg/ai-packs?pack=starter"
```

```
✅ pack uninstall: removed
Run `replix` to remove generated files.
```

---

## Lock your packs (recommended for teams)

```bash
npx replix lock update
```

```
🔒 Lock updated: replix.lock.json
  starter: rev=abc1234 checksum=sha256:deadbeef... requiredVars=[]
  content: rev=abc1234 checksum=sha256:cafebabe... requiredVars=[]
```

Commit `replix.lock.json`. Teammates get exact same revisions on `replix`.
