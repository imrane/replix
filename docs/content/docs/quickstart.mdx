---
title: Quickstart (No Nix)
description: Install Replix, add a pack by name, apply, and verify in under 3 minutes.
---

## Copy-paste (macOS/Linux)

```bash
cd /path/to/your/repo
npm i -D replix
npx replix add github:owner/rpacks starter
npx replix
npx replix check
```

## Why this is the best first flow

- You see value fast.
- You avoid advanced flags at the start.
- You still get a verification step.
