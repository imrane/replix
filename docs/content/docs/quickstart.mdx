## What you'll do

You'll install Replix, add the `starter` pack (which ships a `repo-status` skill, a `/review` command, and a security agent), apply it to your repo, and confirm it worked.

## Step 1 — Install Replix

```bash
cd /path/to/your/repo
npm install -D replix
```

## Step 2 — Add a pack

```bash
npx replix add github:myorg/ai-packs starter
```

Expected output:

```
🔍 Resolving github:myorg/ai-packs starter...
✅ replix add: added
   source: github:myorg/ai-packs?pack=starter@abc1234
   pack: starter-pack
```

This registers the pack in `.replix/packs.json`. Nothing is written to your repo yet.

## Step 3 — Apply

```bash
npx replix
```

Expected output:

```
🔧 Replix: loading config...
📦 Replix: emitting outputs...
✅ Replix: done
```

Replix has now written the pack's artifacts into your repo:

```
.claude/skills/repo-status/       ← repo-status skill (Claude reads this)
.claude/commands/review.md        ← /review slash command
.claude/agents/security.md        ← security agent
.mcp.json                         ← MCP server config
.opencode/skills/repo-status/     ← same skill for OpenCode
.opencode/command/review.md
.opencode/agent/security.md
opencode.json
```

## Step 4 — Verify

```bash
npx replix check
```

Expected output (in sync):

```
✅ outputs in sync
```

Expected output (drift — run `replix` to fix):

```
❌ outputs drifted from config
  ADD    .claude/skills/repo-status/SKILL.md
  ADD    .claude/commands/review.md
Run `replix` to regenerate.
```

## You're done

Your AI agent now has the starter pack's skill, command, and agent available. Open your editor, start a coding session, and type `/review` to use the command.
