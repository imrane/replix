---
title: Concepts
description: What Replix does in plain language.
---

Replix helps you apply reusable packs to a repo safely.

- **Pack**: a reusable set of skills, commands, agents, hooks, or MCP config.
- **Add**: register a pack source in your repo.
- **Apply**: generate/update files from enabled packs.
- **Check**: confirm generated files are in sync.

Benefit: repeatable setup without copy-paste drift.
